# 🍻 영수증 OCR & 복합 N빵 정산 봇 (Settlement Agent)

> **"영수증 찍고, '술 안 마신 2명 빼줘' 한마디면 끝!"**  
> 영수증 OCR 문자인식과 자연어 넛지 처리 기술을 결합하여, 1원 오차 없는 정산 계산과 기분 안 상하는 맞춤형 카톡 독촉 메시지를 제공합니다.

---

## 📌 1. 프로젝트 개요 (Project Overview)

* **문제 정의:**  
  * 복잡한 술자리 모임(1차 고깃집, 2차 노래방 등)에서 차수별 중도 이탈자 및 특정 메뉴(술, 디저트 등) 미이용자 발생 시 기존 정산 앱으로는 정확한 계산이 어려움.
  * 총무가 엑셀로 일일이 계산하는 수기 피로도와, 정산 금액 공유 후 송금을 지연하는 인원에게 다시 돈을 요구할 때 느끼는 사회적·심리적 부담 존재.
* **핵심 기능:**
  1. **영수증 OCR 문자인식:** 영수증 사진을 찍으면 총 결제 금액 및 세부 메뉴 항목 자동 파싱.
  2. **자연어 예외 조건 보완:** "1차 5명 중 2명은 술 안 마셨어", "2차는 희주 빠짐" 등 대화형 문장 입력 시 파싱 엔진이 조건 자동 반영.
  3. **Python 정밀 N빵 엔진:** LLM 계산 환각을 차단하고 1원 단위까지 정확한 인당 부담금 산출.
  4. **맞춤형 독촉 카톡 생성:** 정중/친근/유쾌 등 상대방과의 관계에 맞춘 톤별 독촉 메시지 자동 생성.
