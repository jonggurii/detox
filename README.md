# 모아정산 | 복합 N빵 정산 MVP

> 2026학년도 2학기 아주대학교 AI 캡스톤디자인 · **11조 Detox**  
> 서비스명: **모아정산**  
> 대상 사용자: 모임에서 여러 차수의 비용을 대신 결제하고 정산하는 총무, 대학생 및 직장인

## 1. 서비스 소개

모아정산은 여러 차수의 모임에서 **참여 인원 변화, 술값 제외, 항목별 분담, 찬조금** 등 복잡한 조건을 반영해 개인별 정산 금액을 계산하도록 돕는 MVP입니다.

일반적인 소위 N빵이라고 하는 균등 분할만으로 해결하기 어려운 상황에서 총무가 메모장과 계산기를 오가며 반복 계산하는 부담을 줄이는 것을 목표로 합니다.

### MVP 핵심 체험
- **자연어 정산 입력**: 누가 참석하고 누가 결제했는지, 비용과 분담 조건을 문장으로 입력
- **영수증 이미지 + 설명 입력**: 영수증 사진과 정산 조건을 함께 제공하여 AI 분석 결과 확인
- **조건 검토 및 확정**: 분석된 참여자·금액·분담 조건을 확인한 뒤 정산 진행
- **개인별 정산 결과 확인**: 각 참여자의 부담 금액과 정산 결과 확인

> 실제 화면에서 제공되는 버튼 명칭과 지원 범위는 배포된 MVP 버전에 따라 다를 수 있습니다. 송금 자동 실행, 메신저 자동 발송 등은 검증된 기능으로 간주하지 않습니다.

## 2. 실행 및 접속 방법

### A. 웹 브라우저로 접속

- **서비스 주소:** https://detox-7o9w.onrender.com/
- **API 문서:** https://detox-7o9w.onrender.com/docs
- 권장 환경: 최신 Chrome 또는 Edge

**배포 상태 안내:** 웹 주소가 아직 구버전 UI를 보여줄 수 있습니다. 최신 Expo UI의 웹 배포는 별도 확인이 필요합니다. 웹 UI와 모바일 UI가 다를 경우 최신 기능 체험은 아래 Android 앱 또는 로컬 Expo 실행을 기준으로 확인해 주세요.

### B. Android 앱으로 체험

- **APK 설치 링크:** `[https://expo.dev/accounts/blossom1851/projects/mobile/builds/6c05338f-065c-4003-9484-ec007ec41dec]`
- 지원 환경: Android 스마트폰
1. 팀에서 제공한 APK 파일을 내려받습니다.
2. 기기에서 설치를 허용하고 앱을 설치합니다.
3. 인터넷 연결 상태에서 앱을 실행합니다.
4. 정산 요청을 입력하거나 영수증 이미지를 선택합니다.

### C. 개발 환경에서 실행 (선택)

저장소: https://github.com/jonggurii/detox  
체험 기준 브랜치: `SongGeon`

**모바일 앱(Windows PowerShell)**

```powershell
git clone -b SongGeon https://github.com/jonggurii/detox.git
cd detox\mobile
npm.cmd install
$env:EXPO_PUBLIC_API_URL="https://detox-7o9w.onrender.com"
npx.cmd expo start
```

터미널에 표시되는 안내에 따라 Expo Go 또는 웹 브라우저를 선택합니다. 웹에서 실행하려면 `npx.cmd expo start --web`을 사용할 수 있으나, 이미지 선택·업로드 등 일부 기능은 웹 호환성 확인이 필요합니다.

**백엔드 로컬 실행(개발자용)**

```powershell
cd detox
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PYTHONPATH="src"
$env:GEMINI_API_KEY="본인의_API_키"
python -m uvicorn app:app --reload
```

- API 기본 주소: `http://127.0.0.1:8000`
- Gemini 기반 분석에는 유효한 API 키가 필요합니다.
- 개발 환경에서는 `SETTLEMENT_DB_PATH` 등 설정에 따라 데이터 저장 위치가 달라질 수 있습니다.
- Python 및 Node.js는 프로젝트 의존성에 호환되는 버전을 사용하세요.

## 3. 핵심 기능 체험 시나리오

**사용자 역할:** 친구들과 모임을 진행하고 비용을 먼저 결제한 총무  
**체험 목표:** 술을 마시지 않은 참석자를 술값에서 제외하고 개인별 부담액을 확인하기

### 시나리오 1 — 자연어로 복합 정산

1. 모아정산을 실행하고 정산 입력 화면으로 이동합니다.
2. 다음 예시 문장을 입력합니다.

   > 민수, 지훈, 영희 세 명이 식사했어. 식사비 60,000원과 술값 24,000원을 민수가 모두 결제했어. 식사비는 세 명이 똑같이 나누고, 술값은 민수와 지훈만 나눠 내. 영희는 술을 마시지 않았어.

3. AI가 추출한 **참여자, 결제자, 항목별 금액, 술값 제외 조건**을 확인합니다.
4. 조건이 잘못 인식됐다면 수정하거나 문장을 보완한 뒤 다시 분석합니다.
5. 정산을 확정하고 개인별 부담액을 확인합니다.

**기대 결과(예시 조건대로 정확히 계산된 경우)**

| 참여자 | 식사비 | 술값 | 최종 부담액 |
|---|---:|---:|---:|
| 민수 | 20,000원 | 12,000원 | 32,000원 |
| 지훈 | 20,000원 | 12,000원 | 32,000원 |
| 영희 | 20,000원 | 0원 | 20,000원 |
| **합계** | **60,000원** | **24,000원** | **84,000원** |

민수가 전액 결제했으므로, **지훈은 민수에게 32,000원, 영희는 민수에게 20,000원**을 송금해야 합니다. 민수의 본인 부담액은 32,000원입니다.

> 위 금액은 예시 입력의 산술적 기대값이며, 실제 배포 앱에서 동일하게 표시되는지는 테스트로 확인해야 합니다.

### 시나리오 2 — 영수증 사진과 설명으로 입력

1. 앱에서 영수증 이미지 분석 기능을 선택합니다.
2. 실제 개인정보가 없는 테스트 영수증 사진(JPG/PNG 등)을 선택합니다.
3. 다음과 같이 추가 조건을 입력합니다.

   > 민수, 지훈, 영희가 함께 식사했고 민수가 전액 결제했어. 술은 민수와 지훈만 마셨어.

4. 분석 결과에서 **영수증 항목·금액·참여자·분담 규칙**을 검토합니다.
5. 누락되거나 잘못 인식된 정보가 있다면 수정 후 확정합니다.
6. 최종 정산 결과를 확인합니다.

영수증 사진만으로는 누가 어떤 음식을 소비했는지 확정할 수 없으므로, **추가 조건 입력 및 사용자 검토가 필요**합니다.

### 다른 입력으로 다시 체험하기

새 정산을 시작하거나 입력 화면으로 돌아가 참여자, 결제 금액, 차수, 제외 대상을 변경하여 다시 분석합니다. 기존 결과를 덮어쓰는지 또는 새 세션으로 저장되는지는 화면의 안내를 확인하세요.

## 4. 정상 동작 확인 방법

- 정산 조건 분석 후 참여자와 금액이 입력 내용에 맞게 표시되는지 확인합니다.
- 특정 항목에서 제외한 사람이 해당 항목 비용을 부담하지 않는지 확인합니다.
- **개인별 부담액 합계가 전체 지출 금액과 일치하는지** 확인합니다(찬조금·기타 공제는 별도 반영).
- 누가 먼저 결제했는지에 따라 송금해야 할 대상과 금액이 적절히 나타나는지 확인합니다.
- 입력을 변경했을 때 변경된 조건이 새 결과에 반영되는지 확인합니다.

## 5. 계정, 테스트 데이터 및 주의사항

- **테스트 계정:** 현재 확인된 별도 계정 발급 절차 없음. 접근 제한이 추가됐다면 팀 안내에 따르세요.
- **사전 준비:** 인터넷 연결, 테스트용 참여자 이름·금액, 이미지 체험 시 영수증 샘플
- **개인정보:** 실명, 계좌번호, 실제 결제 정보가 포함된 영수증은 테스트에 사용하지 마세요.
- **보안:** 현 MVP의 세션 접근 통제가 충분히 검증되지 않았으므로 공개 테스트에는 가상 데이터만 사용하세요.
- **AI 분석:** Gemini 분석 결과에는 인식 오류가 있을 수 있으므로 계산 전에 사용자가 반드시 확인해야 합니다.

## 6. 알려진 제한 및 오류 대응

| 현상 | 원인 및 대응 |
|---|---|
| 첫 접속 또는 첫 요청이 느림 | Render 무료 서버는 유휴 상태에서 휴면하며, 재가동에 시간이 걸릴 수 있습니다. 잠시 기다린 뒤 재시도해주세요. |
| 웹사이트가 구버전 UI로 표시됨 | Expo Web 정적 빌드가 Render에 반영됐는지 확인해야 합니다. 최신 UI 배포 완료 전에는 Android 앱으로 체험하세요. |
| AI 분석이 실패함 | 인터넷 연결, 서버 상태에 따라 발생할 수 있습니다. 재시도를 통해 해결할 수 있습니다. |
| 이미지 업로드가 웹에서 실패함 | 웹과 Android의 파일 처리 방식이 다를 수 있습니다. Android 앱으로 재시도하고 오류를 팀에 공유하세요. |
| 저장한 정산 내역이 사라짐 | Render 무료 인스턴스의 로컬 파일 시스템은 영구 저장소가 아닙니다. SQLite 데이터가 재시작·재배포 시 유실될 수 있습니다. |
| 기능이나 화면이 안내와 다름 | 배포 버전과 브랜치가 일치하는지 확인하고 팀에 알려주세요. |

**운영 제한:** Render Free는 상시 가동이 보장되지 않으며, 무료 인스턴스 시간 등 사용 제한이 있습니다. 본 MVP는 결제·송금이 실제로 실행되는 금융 서비스가 아니라 정산 계산을 보조하는 테스트용 소프트웨어입니다.
