# 문제 정의서

## 왜 만드는가

### 한 문장 문제

주 1회 이상 모임을 주최하는 총무(정산자)가 차수별 중도 이탈자 및 특정 메뉴(술 등) 미이용자의 차액 정산 조건이 복잡하여 수기 계산 피로와 송금 독촉 시 심리적 부담을 겪는다.

### 대상과 비대상

- **1차 사용자:** 모임 총무(정산자), 술자리와 회식 정산 주최자
- **비대상:** 기업 법인카드 정산 담당자, 1:1 단순 계좌 이체 사용자

## 인터뷰 증거

인터뷰 프로토콜과 Job Story는 [research/interviews.md](research/interviews.md)에 있다. 아래 로그 번호는 인터뷰 원자료의 증거 식별자를 보존한다.

| 관찰된 문제 | 증거 | 해석 |
|---|---|---|
| 복잡한 차액 수기 계산 피로 | “술 안 마신 친구 정산해 주다 엑셀 켰어요” (로그 1, 3) | 단순 1/N이 아닌 차수·항목별 계산이 핵심 부담이다. |
| 송금 독촉의 심리적 부담 | “돈 달라고 카톡 여러 번 보내기 민망해요” (로그 4, 5) | 계산 완료 뒤에도 회수 커뮤니케이션 비용이 남는다. |

## 반증 조건

- **문제 실재:** 대상 사용자 10명 중 최근 한 달 내 복잡한 N빵 정산 때문에 수기 계산을 하거나 독촉을 미룬 사례가 3명 미만이면 문제 가설을 기각한다.
- **해결 가설:** 자연어 예외 정산 결과를 받은 뒤 사용자가 엑셀이나 계산기를 별도로 열어 재검증하는 경우가 반복되면 해결 가설을 기각한다.

## 성공의 정의

- 정산 결과를 복사하고 카카오톡으로 공유하는 비율이 측정된다.
- 다음 모임에서 같은 사용자가 다시 정산을 요청하는 재사용률이 측정된다.
